## 🔖 Overview
'Money Planner'(머플러)는 사용자의 소비 습관 개선을 돕는 소비 관리 앱입니다. 
<br>
목표 금액과 카테고리별 예산을 설정하고 하루 단위로 소비 기록과 자가 평가를 할 수 있으며, 목표 기간 동안의 소비 데이터를 리포트로 확인할 수 있습니다.
